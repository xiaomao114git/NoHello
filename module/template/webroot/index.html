属性服务通道 (resetprop)
开启后 NoHello 会用 props.conf 里的属性覆盖系统属性服务 (__system_property_get / getprop)。全局生效，建议只对目标应用 所在场景使用。挂载通道 (build.prop bind-mount) 始终生效，无需此开关。

props.conf 编辑

每行 key=value。修改后保存会立即刷新 build.prop (挂载通道) 并在开启时 重放 resetprop (属性通道)。

Hide Rule System mount tmpfs

用空 tmpfs 覆盖目录，让反作弊对子路径的探测 (/sys/module/module_00 等) 全部 落空 (ENOENT)。内置默认: /sys/module、/data/local/tmp。
